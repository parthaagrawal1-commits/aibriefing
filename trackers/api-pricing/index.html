How to read this

Input vs output. You pay for the tokens you send (input) and the tokens the model writes back (output). Output is typically 5x the input rate, so verbose answers cost far more than long prompts.

Cached input. If you send the same long prefix repeatedly (a system prompt, a document), vendors charge a much lower rate for the repeated part, usually 2.5–10% of the input price. Anthropic charges a premium to write the cache; OpenAI charges 1.25x input for cache writes on GPT-6 Astra.

Batch. All three vendors offer roughly 50% off for asynchronous jobs that can wait minutes to hours.

Tiers and cliffs. Some models charge more above a prompt-length threshold (OpenAI above 272K input tokens, Gemini Pro above 200K, Claude Haiku 5.5 above 100K), and the surcharge applies to the whole request. Anthropic's current flagship tiers include the full 1M window at one price.

Introductory pricing. Google's Gemini 4 Argon and the 3.x Flash models carry published end dates for launch pricing, and OpenAI's GPT-5.6 Sol promotional rate ($4 / $20) ends November 30, 2026, returning to $5 / $30. Build those dates into any cost forecast.

Tokenizers differ. Anthropic notes that Claude 4.7 and later produce roughly 30% more tokens for the same text than earlier models. Compare cost per task, not cost per token.

Common questions

What is the cheapest frontier-class model right now?

Among current flagship tiers, Anthropic's Claude Sonnet 5.5, OpenAI's GPT-6.1 Sol and Google's Gemini 4 Argon all list at $2 / $10, though Argon doubles on December 1. Below that, OpenAI's GPT-6.1 Terra is $1 / $5 and GPT-6 Luna $0.10 / $0.50; Thinking Machines' Inkling 2 Small is $0.30 / $1.00 on Tinker.

Why do output tokens cost more than input tokens?

Generating text is sequential and compute-heavy, while reading a prompt can be processed in parallel. Vendors price output at roughly 5x input to reflect that.

How do I estimate my monthly API bill?

Multiply average input tokens per request by the input price, add average output tokens times the output price, divide by one million, then multiply by monthly requests. Apply cache and batch discounts where they fit your workload.
