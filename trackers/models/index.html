Common questions

Which model is the most capable right now?

There is no single answer across tasks. The top tiers are OpenAI's GPT-6 Astra, Anthropic's Claude Fable 5.1 and Google's Gemini 4 Argon; vendor-published benchmarks favour the vendor publishing them, so compare independent evaluations for your specific workload.

What does 'open-weight' mean?

The model's trained parameters are published so anyone can download and run it, as Mistral did with Mistral Large 4. Closed models such as GPT-6 Astra are only reachable through the vendor's API.

How is this list kept current?

A nightly pass checks the major labs' announcement pages, API changelogs and pricing pages and adds any new release with a link to the vendor's own page.
