Nov 19, 2026 · DevelopingJava4Shell: CVE-2026-114938 is an out-of-bounds write in OpenJDK's accelerated Base64 code, patched by Oracle on November 17; it fires before application input validation and affects every JVM on AVX-512 VBMI hardware

Security firm Calif disclosed a memory-corruption bug in the Java runtime on Monday, the same day Oracle shipped fixed builds for Java 8 through 27 and GraalVM. Because the flaw lives in the JVM's vectorised Base64 decoder, malformed input is processed before any application code can reject it, and an unauthenticated attacker may be able to execute code; early reports score it 9.2 under CVSS 4.0 while Oracle's own scoring tops out at 8.1. Cloudflare says it has seen no exploitation yet, has shipped six log-only WAF rules as a compensating control, and is rolling out a JVM flag that disables the accelerated routine. Technical details are being withheld until patches propagate.

DevelopersTemurin, Corretto, Zulu and Red Hat builds carry different version numbers from Oracle's; check your base images and the JDK bundled inside Jenkins, Kafka, Elasticsearch and Tomcat appliances rather than only the one on your PATH.

Nov 18, 2026 · Microsoft's agent-framework package on PyPI poisoned for 45 minutes: versions 1.26.1 and 1.26.2 ran a credential stealer at every Python start-up, harvesting Azure, AWS, GitHub and npm secrets

Two malicious releases of Microsoft's agent-framework Python package, the entry point for the Microsoft Agent Framework with roughly 190,000 downloads a month, were uploaded to PyPI at 20:35 and 21:08 UTC on Monday and removed by about 21:30. The wheels kept the legitimate code and added a .pth file to site-packages so a stealer executed whenever any Python interpreter started, collecting environment variables matching TOKEN, SECRET, KEY, AZURE, AWS, GITHUB and NPM, dozens of credential files, Azure managed-identity and DevOps tokens, and in the second version GitHub Actions OIDC tokens, then posting one compressed blob to a webhook.site address. Wiz, which published the full analysis, says the free-tier webhook capped collection at 100 requests, so at most about 50 victims' data was captured. No malicious code appears in Microsoft's GitHub repository and no source distribution was published, which points to the packages being built outside the normal release process; Microsoft says it is investigating.

DevelopersPin to 1.26.0 or wait for Microsoft's statement before upgrading. The .pth trick means a transitive dependency you never import can still own your interpreter; add .pth creation to what your supply-chain scanner flags.
Source: Wiz Research analysis · SecurityWeek · The Hacker News

Nov 17, 2026 · BIS interim final rule: licence required for chips feeding any data centre that gives China-linked firms more than 12 million TPP; Singapore, Malaysia, Indonesia, Thailand and Brazil added; AI Diffusion Rule rescinded

The Bureau of Industry and Security released 'Addressing Remote Access to Advanced Semiconductors' on Monday, saying it was written at the direction of the Treasury Department and the National Security Council. A new end-use control (section 744.24) requires a licence to export or transfer advanced chips, servers and related software when the exporter knows they will go to a data centre, anywhere in the world, that provides more than 12 million aggregate total processing performance to companies headquartered in or ultimately owned from China, Macau or other Country Group D:5 destinations; linked facilities are counted together, and a non-Chinese customer that trains or supplies models for a D:5 company is also in scope. Five destinations judged to carry elevated diversion risk now need a licence for all advanced computing items, with US-headquartered end users exempt only if the exporter files monthly reports. The rule takes effect on Federal Register publication, expected November 19, with comments due 60 days later and existing arrangements given 90 days to apply for a licence. A trade-law analysis puts 12 million TPP at roughly 760 H100-class or about 220 B300-class chips.

DevelopersThe rule rests on the Export Administration Regulations rather than the Remote Access Security Act, which the House passed 369 to 22 in January and the Senate has not taken up. If you ship inference endpoints from leased offshore GPUs, this is the rule your legal team will cite when it asks where the hardware sits and who else uses it.

Nov 17, 2026 · macOS 27.3 beta tightens Full Disk Access because of AI agents: apps that touch protected files are silently denied and no longer surface a one-click toggle; a 'Private Folders' permission is in the code

Apple's macOS 27.3 beta, in developer testing since November 2 and expected to ship in December, changes how apps obtain Full Disk Access, the permission that unlocks Mail, Messages, Safari data and Time Machine backups. Today an app that is denied a protected file is added to the Full Disk Access list so a user can enable it with one switch; in the beta, code examined by the developer known as pdfu shows the attempt is denied and logged but the app is not listed, so users must add it by hand in System Settings. Apple said in an October 2 developer post that such access should require 'very explicit user action' and that the risk 'will grow substantially' as AI agents become more capable and autonomous. The beta also contains references to a folder-by-folder 'Private Folders' permission, not yet functional, that could let an assistant read, say, the iMessage database without everything else. Monday's beta 2 reportedly adds warnings and controls over what AI automation apps can see and do; Apple has not published release notes describing them.

DevelopersIf your Mac agent asks for Full Disk Access to read messages or mail, your onboarding breaks in December. Build the manual-add flow now and design for a scoped folder permission arriving later.

Nov 16, 2026 · Project Zero scraps the 30-day soak period: bugs go public 90 days after reporting now, 60 from February 2, 30 from January 2028, fixed or not

Google's Project Zero published its 2026 disclosure policy on November 13, replacing the '90 + 30' rules in place since 2021 with 'Full X': details are released X days after the vendor is told, regardless of fix status, severity or variants. The team's stated reason is that LLM tooling lets attackers find bugs and turn patches into exploits almost immediately, so patch soak time is 'no longer meaningful', and that it now finds several vulnerabilities a week where it once found a few a year. Vendors objected that a hard clock would expose unfixed bugs and push them to fix Project Zero's reports ahead of worse ones; the phased schedule is the compromise. In-the-wild bugs stay on Google's seven-day policy.

DevelopersThe mechanisms Project Zero says it expects vendors to build are feature flags, input filtering, authenticated alternate update channels and hotpatching. If you cannot turn a code path off in production without a release, start there.

Nov 16, 2026 · Corelight: 23 of 35 popular MCP servers resolve dependencies from public registries on every launch; one commit-pinned server ran 15 different dependency sets in five weeks

Corelight's James Lagermann measured how the MCP servers that AI assistants launch actually get their code and found that 23 of 35 use a recommended install, typically npx or uvx, that resolves dependencies from a public registry on every launch or build. A server pinned to one release and one commit ran with 15 distinct dependency sets over five weeks as 23 of its 69 transitive packages changed, including the cryptography library, a JWT library that moved through four versions and the MCP SDK itself; endpoint telemetry showed 17 to 21 rebuilds per server a month and one server launched 162 times in a week. The Cloud Security Alliance's note pairs the finding with the March axios compromise and CVE-2025-6514 in mcp-remote.

DevelopersPin with package@x.y.z or --from 'tool==x.y.z', add a release-age cooldown (npm min-release-age, pnpm minimumReleaseAge, uv exclude-newer), set ignore-scripts, and prefer digest-referenced containers for anything with credentials. Treat MCP config files as code that needs review.

Nov 15, 2026 · FBI FLASH alert: ARTEX agents reached privileged access in under three hours; 1,600+ consoles still exposed after the GitHub takedown

The FBI issued FLASH-20261113-001 on Thursday, its first alert devoted to an AI-driven attack framework.
