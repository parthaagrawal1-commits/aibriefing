Nov 23, 2026 · DevelopingAnthropic mathematician Levent Alpöge posts a Lean-checked claimed proof of the Riemann hypothesis developed with Claude; James Maynard puts it at '98 or 99 percent', Brian Conrad calls the release 'outrageous'; a Navier–Stokes blow-up claim lands the same day

On Friday Alpöge published a four-page note and a Lean formalisation claiming a proof of the Riemann hypothesis and its generalisation, with no human-readable paper; MIT's Andrew Sutherland compiled the code independently and a check that the formal statement matches RH was pending. Nov 19, 2026 · DevelopingJava4Shell: CVE-2026-114938 is an out-of-bounds write in OpenJDK's accelerated Base64 code, patched by Oracle on November 17; it fires before application input validation and affects every JVM on AVX-512 VBMI hardware

Security firm Calif disclosed a memory-corruption bug in the Java runtime on Monday, the same day Oracle shipped fixed builds for Java 8 through 27 and GraalVM. Because the flaw lives in the JVM's vectorised Base64 decoder, malformed input is processed before any application code can reject it, and an unauthenticated attacker may be able to execute code; early reports score it 9.2 under CVSS 4.0 while Oracle's own scoring tops out at 8.1. Cloudflare says it has seen no exploitation yet, has shipped six log-only WAF rules as a compensating control, and is rolling out a JVM flag that disables the accelerated routine. Technical details are being withheld until patches propagate.

BeginnersA flaw in the software layer that runs a huge share of business applications lets a stranger send a specially shaped message and potentially take control. The fix is out; the hard part is finding every copy.

Nov 19, 2026 · Perplexity gives its Computer agent an overnight memory called Brain: a context graph of what the agent did, what failed and what was corrected, with answer correctness up 25% on repeated tasks and cost down 13%

Perplexity's Brain records the work its Computer agent performs, not the user's preferences, and reviews that record on a schedule, typically overnight, to rewrite the skills and context the agent loads next time.
