Nov 24, 2026 · Z.ai releases GLM-5.4, a roughly 750B 'Loop Transformer' that runs a 28-layer block twice per token, with image input and a 1M context, to Coding Plan subscribers only: no benchmarks, no API price and no weights yet

Z.ai converted the trained GLM-5 base through continued training rather than pretraining a looped model, with per-token gates controlling the second pass and the pass reusing the first pass's KV cache; it claims capability comparable to models of two to three trillion parameters but has published only a 30B ablation showing eight to eleven points of gain on maths and science for about 10% more compute. The release follows Thinking Machines' Inkling 2 Mini, which loops its middle layers three times to fit in 20 GB. An API is promised after safety evaluation and weights after hardening, without dates; GLM-5.3 stays the API model at $1.40 / $4.40.

Nov 24, 2026 · Google DeepMind uses teams of Gemini 4 agents and Lean 4 proofs to find quantum algorithms with formally verified correctness, cutting the computing cost of a fusion simulation 11.8x and a state-preparation routine 290x

Each problem got an independent team of agents whose proposals were checked in Lean before entering a shared notebook, with teams exchanging ideas every four hours; every result is a proved Hoare triple with resource bounds, checked by an independent comparator against frozen specifications, because the circuits cannot be tested classically or on current hardware. The blog reports the inertial-confinement-fusion computation falling from 5,650 to 4,338 error-corrected qubits, a photochemistry problem 8x cheaper and a cytochrome P450 simulation 2.5x, with the Lean library and solutions open-sourced; the optimised circuits still exceed what the first error-corrected machines will offer.

BeginnersThe AI did not run a quantum computer; it found shorter recipes and proved, mathematically, that they are correct.

Nov 19, 2026 · DevelopingJava4Shell: CVE-2026-114938 is an out-of-bounds write in OpenJDK's accelerated Base64 code, patched by Oracle on November 17; it fires before application input validation and affects every JVM on AVX-512 VBMI hardware

Security firm Calif disclosed a memory-corruption bug in the Java runtime on Monday, the same day Oracle shipped fixed builds for Java 8 through 27 and GraalVM. Because the flaw lives in the JVM's vectorised Base64 decoder, malformed input is processed before any application code can reject it, and an unauthenticated attacker may be able to execute code; early reports score it 9.2 under CVSS 4.0 while Oracle's own scoring tops out at 8.1. Cloudflare says it has seen no exploitation yet, has shipped six log-only WAF rules as a compensating control, and is rolling out a JVM flag that disables the accelerated routine. Technical details are being withheld until patches propagate.

BeginnersA flaw in the software layer that runs a huge share of business applications lets a stranger send a specially shaped message and potentially take control. The fix is out; the hard part is finding every copy.

Nov 19, 2026 · Perplexity gives its Computer agent an overnight memory called Brain: a context graph of what the agent did, what failed and what was corrected, with answer correctness up 25% on repeated tasks and cost down 13%

Perplexity's Brain records the work its Computer agent performs, not the user's preferences, and reviews that record on a schedule, typically overnight, to rewrite the skills and context the agent loads next time. Every memory entry links back to the session, file or source it came from. On early internal measurements the company reports a 25% rise in answer correctness on tasks the agent has seen before, a 16% rise in recall and a 13% fall in the cost of tasks that need historical context.
