Google puts a date on it: AI agents must use Workspace MCP instead of REST from February 1, 2027

Workspace MCP servers and the CLI went generally available on November 24 with free and paid tiers, the same day Anthropic made MCP Tasks GA and put Skills over MCP into beta.

Why it matters
DevelopersIf your agent calls Gmail, Drive or Calendar REST endpoints directly, you have until February 1, 2027 before technical enforcement. Billing for the Scaled tier starts April 1, 2027, charged only above the daily free allowance.
ExecutivesWorkspace admins get agent audit logs, human-in-the-loop confirmation rules and API controls in one place. The governance story for agents touching corporate email just got concrete.
SecurityAgents must identify themselves in OAuth and existing DLP rules apply automatically. The addendum bars long-term storage of certain data and API scraping — read it before you build a retrieval cache.
ML engineersTool search in multi-server setups can cut tool-definition context by over 85% per Anthropic's figure, which changes how many servers you can attach before the context budget decides for you.

November 24 produced two announcements that belong together. Google made its Workspace MCP servers and official Workspace CLI generally available, with standardized usage tiers, new admin policies and an AI Tools Addendum. Anthropic made MCP Tasks and Elicitation generally available in Claude and Claude Code, and put Skills over MCP into public beta. One is the largest data estate in enterprise software declaring a protocol mandatory; the other is the protocol's author adding the pieces that make a server more than a tool list.

What Google actually committed to

MCP servers now cover Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks, with Keep to come, and the CLI targets terminal, virtual machine and container agents. Two tiers: Standard is free with published rate limits, Scaled offers higher quotas, starting with Gmail, Drive and Calendar. Google says over 99% of active developers sit inside Standard. Charging for Scaled begins April 1, 2027, and only for usage above the daily free allowances; projects that neither switch nor get marked internal fall back to Standard limits.

The date that matters more is February 1, 2027, when Google begins technically enforcing that AI agents use MCP rather than calling the REST APIs directly. That is a migration deadline with teeth, announced with roughly fourteen months of notice for billing and ten weeks of notice for enforcement. Google promises at least 90 days' notice for changes and excludes Workspace APIs from Cloud Support's variable fee until at least December 2027.

For administrators, access for external AI tools, MCP servers, the CLI and APIs is managed in one place in the Admin console under Security → API Controls. Admins can set human-in-the-loop confirmation rules and read agent audit logs, agents must identify themselves in OAuth, and existing DLP rules apply without reconfiguration. Granular agent policies are promised "over the coming months" — the gap to watch.

What Anthropic added

Tasks and Elicitation are GA for Pro, Max and Ultra and rolling out to Team and Enterprise. Tasks let a server run work that outlives a single request; Elicitation lets it ask the user for something mid-flight, with Supabase, Railway and GitHub named as adopters. Skills over MCP — a server shipping instructions, not just tools — is in public beta, on by default for Pro, Max and Ultra, needing an admin to enable it on Team plans, with Shopify, HubSpot and Atlassian live and Carta coming. File uploads are listed as rolling out soon. Anthropic puts the ecosystem at over 10,000 connectors for Claude and over 700 million monthly SDK downloads, and says tool search can cut tool-definition context by more than 85% in multi-server setups.

The shape of the bet

Two years after MCP was published, the protocol has moved from a convention between Claude and a handful of servers to the access path a platform vendor will enforce. That is good for anyone who was going to build integrations anyway, and it changes the negotiating position of everyone who was not: the alternative to speaking MCP to Workspace is, from February, no programmatic agent access at all. The free tier covering 99% of developers is the sweetener, and the April 2027 billing date is the part to model.

The caution is that "agents must use MCP" and "MCP is secure" are different claims. A protocol that standardises how a model reaches eight Google apps also standardises the blast radius of a credential, and Skills over MCP means a server can now ship the instructions the model follows, not merely the functions it calls. The last month supplied the counter-examples: router endpoints losing zero-data-retention status, a poisoned package in an agent framework, an agent committing a credential to a public repository.

What to do

Inventory every agent and automation that touches Workspace REST endpoints and give each one an owner and a February deadline. Decide now whether each project is internal — the marking that preserves higher limits inside your subscription — or headed for the Scaled tier, and get the April 2027 cost into next year's budget rather than discovering it. Turn on agent audit logs and set confirmation rules before you need them. On the Anthropic side, if you run Team or Enterprise, decide deliberately whether to enable Skills over MCP, because a server that can ship instructions deserves the same review as a dependency.

What to watch

Whether Google publishes dollar prices for the Scaled tier well before April 2027; what the granular agent policies look like, since today's controls are coarse; whether other suites — Microsoft 365 in particular — set their own MCP deadlines; and whether Skills over MCP reaches Enterprise with admin-level review of what a server's skills contain.
