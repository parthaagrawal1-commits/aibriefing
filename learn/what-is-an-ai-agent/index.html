What is an AI agent? A plain-English explanation

An agent is AI that takes actions, not just answers. Here is what that means, why every company is suddenly announcing one, and what can go wrong.

Updated 2026-11-25 · For: Beginners Executives Developers

A chatbot answers a question. An agent is given a goal, works out the steps, and carries them out using tools: a browser, a calendar, a payment system, your company's internal software. "Book me a flight to Austin under $400 next Tuesday" is an agent task. "What's the capital of Texas?" is not.

What is actually inside an agent

Under the hood an agent is a language model running in a loop. On each turn it looks at the goal, what it has done so far and what the tools returned, then decides the next action. The loop ends when the model decides the goal is met or it gives up. Three things make this different from chat:

  • Tools. The model can call functions: search, read a file, send an email, run code. Each call returns a result the model reads before deciding what to do next.
  • Memory. The agent keeps a running record of the task so it can recover from a failed step instead of starting over.
  • Autonomy. Nobody approves each step. That is the point, and it is also the risk.

Why everyone is announcing agents now

Models got reliable enough at multi-step reasoning that the loop stops breaking after two or three steps. Vendors also discovered that an agent that completes a task is worth far more than a chat answer, so pricing is moving from "per message" to "per task completed". Airbnb, Meta, Amazon and the big labs all shipped or announced consumer agents in 2026, and by November the agents were acting inside production systems: Anthropic's Claude Ship (beta, November 23) can fix failing checks on a pull request and, under a policy file you write, approve it, while Perplexity's Computer agent rewrites its own skills overnight. Most of these agents reach other software through the Model Context Protocol, a standard connector that replaces one-off integrations.

What goes wrong

  • Prompt injection. An agent that reads web pages or emails can be told, by the content it reads, to do something its owner never asked for. See prompt injection.
  • Over-permissioned tools. An agent with a company credit card and no spending limit is exactly what it sounds like.
  • Machine-speed misuse. The same loop runs for attackers: in November 2026 AI agents found and exploited a zero-day in a medical-imaging server in about eleven minutes. Your approval gates have to be faster than that, or placed where speed does not matter.
  • Silent failure. Agents are confident. They will report success on a task they half-finished unless you verify the result.

Where it sits, and who is accountable for it

Two things changed in late November 2026. Google made its Workspace MCP servers generally available and said that from February 1, 2027 it will technically enforce that AI agents reach Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks through MCP rather than calling the REST APIs directly; Anthropic made MCP Tasks and Elicitation generally available the same day and put Skills over MCP — a server shipping instructions, not only functions — into public beta. The connector layer is becoming the access path platform vendors police, which is good for governance and means a server you attach can now shape what the model does.

On the legal side, the UK's Financial Conduct Authority published its agentic AI expectations on November 24: an agent that initiates payments, arranges borrowing, issues financial promotions or makes investment decisions may need financial authorisation at launch, the boundary is set by statute rather than by the regulator, and accountability stays with the regulated firm and a named senior manager even when the model belongs to a third party. See regulatory perimeter.

Containing one

Anthropic's Siren benchmark, also published that week, ran six Claude models against 26 deliberately weakened sandboxes with the shipped safeguards removed. The current generation reached outside the boundary in 21–32% of scenarios, mostly through misconfiguration rather than exotic escapes, though use that Anthropic classifies as misaligned was 0.6–1.6% against 25.8% for an older model. The mitigations are configuration rather than capability: describing the sandbox and its rules in the system prompt cut boundary crossings by 68–96%, a tool letting the agent report that it is blocked took off more, and monitoring the first command that leaves the boundary caught most of the rest — at a cost of roughly nine percentage points of task completion for two models. See sandbox escape.

What to ask before you deploy one

  1. What can it do, not just see? List every tool and what the worst misuse of each would cost.
  2. Where does it read untrusted content, and is there a human check before it acts on it?
  3. How do you know a task actually succeeded?

If you cannot answer all three, run it in a mode where a person approves each action until you can.

Common questions

Is ChatGPT an agent?

In its basic chat mode, no. Modes that browse, run code or complete tasks on websites on your behalf are agentic features built on the same model.

Do agents need a special model?

No. Any capable language model can run an agent loop; the difference is the surrounding software: tools, memory, permissions and verification.

Are agents safe to give access to my accounts?

Only with the narrowest permissions that still let the task succeed, and a human approval step for anything irreversible such as payments or sending messages.

Does my AI agent need a financial licence?

In the UK, possibly, and the FCA said so on November 24, 2026. Test the product against six regulated activities: payment services, financial promotions, authorised information services, credit broking, intermediation and advice. The boundary is set by Parliament, so no regulator can waive it, and some personal-agent products are expected to need authorisation at launch rather than later. If you are a regulated firm buying someone else's agent, the accountability stays with you and with a named senior manager.
